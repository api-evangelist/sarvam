# Sarvam API Docs

> Sarvam AI is an Indian-language AI platform. APIs: Speech-to-Text (Saaras), Speech-to-Text-Translate (Saaras), Text-to-Speech (Bulbul), translation & transliteration (Mayura / Sarvam-Translate), chat completion (Sarvam-30B / 105B), and Document Digitization (Sarvam Vision). Base URL: `https://api.sarvam.ai`. Auth: send your key in the `api-subscription-key` header (auth failures return HTTP 403, not 401). Official SDKs: `sarvamai` on PyPI and npm. Append `.md` to any docs page URL for clean markdown. Full corpus: https://docs.sarvam.ai/llms-full.txt. MCP server (live docs search): https://docs.sarvam.ai/_mcp/server
